# 📧 Email Validator for Mass Enrollment – *Aprendo Pura Vida*

This tool validates email addresses for bulk enrollment in the **Aprendo Pura Vida** platform.

---

## 🚀 Usage

1. **Install dependencies**

   ```bash
   npm i
   ```

2. **Create the data folder**

   In the project root, create a folder named **`data`**, and add your CSV file with user data.  
   Example file name:

   ```
   Default_2025_10_28.csv
   ```

3. **Run the validator**

   Execute the following command in your terminal:

   ```bash
   npm start
   ```

---

💡 **Tip:** Make sure your CSV file follows the expected format (e.g., a list of emails or user records depending on your implementation).
